# Application request

## concept-definition

### definition

An application request is one client's demand for web application work, represented to Flask by a WSGI environment and to application code by request data such as URL, method, headers and body. Matching can associate it with a route and view arguments. The request is one interaction; it is distinct from session information carried between interactions.
