# Application behavior registration

## concept-definition

### definition

An application behavior registration is a declaration connecting application-supplied work to a Flask extension point. Routes select views, hooks act around requests, and processors, error handlers and commands supply other named work. Registering behavior makes it available for later selection; it does not execute that behavior.
