# JSON representation

## concept-definition

### definition

A JSON representation is encoded text or bytes through which application values can be exchanged or decoded. Flask's application-selected provider supplies conversion and JSON response formatting, with default handling for additional Python value forms. The encoding does not determine the business meaning of those values and can be used independently of an HTTP response.
