# File resource

## concept-definition

### definition

A file resource is content an application accesses as a file. Flask can open package-relative resources for reading or instance-relative files with a selected mode, and can adapt selected file content into a response directly or through a static directory. Resource access supplies a handle for application interpretation; file response options instead describe delivery form, cache age and conditional response behavior. Selecting a file does not grant an application access policy or establish delivery.
