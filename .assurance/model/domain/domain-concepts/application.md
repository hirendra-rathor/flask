# Flask application

## concept-definition

### definition

A Flask application is the configured web application instance through which an author supplies behavior and settings to the framework. It holds registrations and service choices, can handle requests, and supplies the application scope for commands, templates and tests. It is distinct from the Python source that creates it and from any particular server process.
