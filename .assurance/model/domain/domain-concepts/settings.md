# Application settings

## concept-definition

### definition

Application settings are the values chosen to customize one Flask application's behavior. They include choices for session signing/cookies, request parsing, development behavior and template integration. Values can be loaded from caller mappings, Python objects/files or environment data. A settings collection is distinct from the behavior registrations whose execution it can qualify.
