# Flask application author

## role-and-contribution

### role-kind

End user

### role

The application author builds an application using Flask, including reusable extension or blueprint contributions. This is a framework consumer role: the author supplies the application-specific behavior and content that Flask integrates.

### contribution

The author declares routes, callbacks, settings and bundles, supplies views/templates/values, uses contextual session and helper services, and can connect framework observers. These interactions support application responses, reusable composition, useful output, continuity and feedback. An extension author's supplied behavior belongs to this role when it builds on Flask rather than changing Flask itself.
